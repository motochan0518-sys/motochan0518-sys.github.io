親御さん向け説明

努力は、見えない所でする。数えるのは、ここだけ。

コソ練部って?

自主練(コソ練)をした日を、毎日みんなで報告し合う、中高生のオンライン部活です。シュートだけでなく、ドリブルや体づくりなど、リングが無い日のコソ練も報告できます。

  • 数えるのは「練習した日」です。シュートでもドリブルでも筋トレでも、やった日は1日。毎週、先週の自分と比べてふり返ります。ほかの部員とは比べません(本数の多さを競う部ではありません)
  • アプリが無くても参加できます。 iPhone なら、シュートを自動で数える無料アプリ「Million Hooper」を使うと、毎日の本数がたまり、積み重ねが目で見えます。部の中に使い方の例もたまり、運営の MOTO も同じアプリで自分の練習を報告します。アプリで数えられない場合は、手で数えた本数でも大丈夫です
  • 週1回、全体ミーティングがあります。その週に「どんな練習をしたか」「次はどんな練習をしたいか」を話し、MOTO が「質の高いコソ練とは」の考え方をお伝えします。質問は、ミーティングの中で手を挙げた人に、みんなの前でお答えします。ミーティングは声で行い、曜日・時間は運営の仕事の都合に合わせて前の週にお知らせします。参加は自由で、出られなかった人は録画で見られます(録画は撮った日から3か月で消します)
  • 部員どうしで、お互いの報告に反応し合う部です。順位はつけません。お互いの報告が刺激になる場所です
  • 休んだ日も「今日は休み」の一言で報告になります。運営から体づくりをすすめるときは、軽いものだけにします

保護者の方へ

  • 「こっそり」は、学校やチームの仲間に対してです。保護者の方は、部の中を全部見られます(保護者用の見学の部屋があります)
  • 保護者の方は部員の部屋を見るだけで、書き込みはできません。保護者の方の発言は保護者専用の部屋で行い、その部屋は部員からは見えません
  • 部を運営する大人は MOTO だけです。Discord でもインスタなどの SNS でも、MOTO は部員とも保護者の方とも個別メッセージをしません。 やり取りはすべて、ほかの人から見える部屋で行います
    • 運営者から保護者の方へのメールは、受付・招待などのお知らせと、安全に関わる時のご連絡だけです(お子さんには個別に連絡しません)
  • 安全のため、部の書き込みは機械(AI)でも確認し、危ない書き込みがあると運営者(MOTO)に知らせが届きます。読むのは安全の確認のためだけです。機械が部員に返事をしたり話しかけたりすることはなく、部を運営する大人は MOTO だけです
  • 部員どうしの個別メッセージは禁止です。本名・学校名・チーム名・住んでいる所・顔の写真は出しません(アイコンも顔写真にしません)
  • 保護者だけの部屋は、ほかのご家庭の保護者の方にも見えます。ご家庭の事情など、ほかの方に見せたくないことは書かないでください
  • ルール違反や、お子さんが嫌な思いをしたときは、保護者だけの部屋でお知らせください
  • 退部は保護者の方からお知らせください。理由は不要です
  • 運営へのご連絡は保護者だけの部屋で。運営は仕事をしながら運営しているため、返事は数日以内になります。ルール違反があった場合は退部していただくことがあります(部のルールは、このページの下の「部のルール」に載せています)
  • お願いするのは、その日の練習の報告(何をしたかの一言。アプリの画面のスクショや本数を付けてもよい)だけです。お試しは5人と少ないので、お試しの間は、できるだけ毎日の報告をお願いしています(短くて大丈夫です)
  • MOTO は仕事の合間に部の中を見ていますが、すべての報告に返事をするわけではありません。部員どうしで反応し合う部にしています
  • 声の部屋は、MOTO がいる時だけ開けます
  • 何か起きたときの対応は、このページの「何か起きた時の手順」をご覧ください
  • 練習やフォームの動画は、出したい部員だけ出せます(出さなくても大丈夫です)。顔が写らない撮り方(後ろや横から、首から下)に限ります。アドバイスがしやすくなるためです
  • 部の中の報告・日記・動画は、スクショなどで部の外に出さないルールです(部員・保護者とも)

対象13歳以上の中学生・高校生
人数1期は5人まで(6人目からは順番待ちとして受け付け、2期で優先してご案内します)。3人そろえば始めます
期間4週間(始まる日は、準備ができ次第メールでお知らせします)
費用無料(将来は有料になる予定です。その時は先にお知らせします)
使うものスマホ・Discord(13歳から使えるアプリ)。iPhone ならシュートを数えるアプリ「Million Hooper」(無料)とスマホ用の三脚(アプリ・三脚が無くても参加できます)
お願いできるだけ毎日の報告(短くて大丈夫。練習しなかった日は「今日は休み」の一言で OK)/ 週1回の全体ミーティング / 最後に短いアンケート
ミーティングの録画週1回のミーティングは録画し、出られなかった部員が見られるように部の中だけに置きます。部の外(YouTube など)には出しません。録画は撮った日から3か月で消します。お子さんの声が入るため、申し込みフォームで同意をいただきます

参加の流れ

  1. 保護者の方から、申し込みフォームでお申し込みください(インスタなどでお子さんから個別メッセージをもらっても、お返事はしていません。MOTO は誰とも個別メッセージをしないためです。お申し込みは必ず保護者の方から、フォームでお願いします)
  2. 保護者の方の同意を確認します
  3. お子さんに Discord の招待をお送りします。保護者の方には見学の部屋の招待をお送りします

お約束できること・できないこと

  • 試合で勝てる・上手くなる、という結果はお約束できません
  • お約束するのは、運営がやることです。週1回の全体ミーティングを開き、「質の高いコソ練とは」の考え方をお伝えする・ミーティングで手を挙げた人の質問に、みんなの前で答える
  • お約束できないこと: すべての報告への返事・個別のご相談(質問はミーティングでみんなの前で受けます)
  • 目指すのは、何を・どれだけ・どうやって練習するかを、自分で決めて続けられるようになることです

バスケのコソ練部 部のルール

部員のルール

  1. 本名・学校名・チーム名・住んでいる所・顔の写真は出さない(呼び名で参加。アイコンも顔写真にしない)
  2. 部員どうしの個別メッセージ(DM)はしない。話すのは部の部屋だけ
  3. 報告は、今日やった練習を一言で書く。シュートでもドリブルでも筋トレでも、やった日が「練習した日」の1日。
    本数や時間・アプリの画面のスクショは、付けたい人だけで OK(アプリで数えられない人は、自分で数えた数字で OK)。休んだ日も「今日は休み」の一言で報告になる。お試しの間は、できるだけ毎日報告する(短くて大丈夫)
  4. ほかの部員の報告をばかにしない。順位はつけない。人とは比べず、毎週、先週の自分と比べる。ほかの人の報告には反応して、まねしたい所を見つける
  5. 保護者の方も部員の部屋を見ています(書き込みはしません)
  6. 嫌なことを言われた・知らない人から DM が来たときは、返事をしないで、おうちの人に話す。おうちの人から運営に伝わります
  7. 部の中のことは、外に出さない。 ほかの部員の報告・日記・動画を、スクショや保存で部の外(SNS・友だち)に出さない
  8. 練習やフォームの動画は出してよい。ただし顔が写らないように撮る(後ろ・横から、首から下)。ほかの人やチーム名が写るものは出さない

運営(MOTO)の約束

  1. Discord でもインスタなどの SNS でも、MOTO は誰とも個別メッセージ(DM)をしない。 部員とも保護者とも、やり取りはすべて、ほかの人から見える部屋で行う。
    運営者から保護者の方へのメールは、受付・招待などのお知らせと、安全に関わる時のご連絡だけ(お子さんには個別に連絡しない)
  2. 部員から個別の連絡(DM)が来ても、返事はしない。「相談は #相談 か、週1回のミーティングで」という案内は、固定の投稿(#ようこそ のよくある質問・#相談 の最初の投稿)でしておく
  3. ケガや体の相談にはお答えしない(医療機関へ)
  4. 体づくりをすすめるときは、軽いものだけにする(成長期のやりすぎを防ぐ)
  5. 週1回の全体ミーティングを声で開く。曜日・時間は前の週にお知らせする。参加は自由。質問は、手を挙げた人にみんなの前で答える(個別の相談は受けない)。先週の自分との比べ方も、ここで話す
  6. 部の中は仕事の合間に見るが、すべての報告に返事はしない。部員どうしで反応し合う部にする
  7. 声の部屋は、MOTO がいる時だけ開ける
  8. 何か起きたときの対応: このページの「何か起きた時の手順」のとおり
  9. ミーティングは録画し、出られなかった部員が見られるように部の中だけに置く。部の外(YouTube など)には出さない。録画は撮った日から3か月で消す
  10. 安全のため、部の書き込みは機械(AI)でも確認し、危ない書き込みは運営者に知らせが届くようにする。読むのは安全の確認のためだけ。機械が部員に返事をすることはない

保護者の方へのルール

  1. 部員の部屋は見るだけ(書き込みはできません)。発言は保護者だけの部屋で
  2. 保護者だけの部屋は、ほかのご家庭の保護者の方にも見えます。ほかの方に見せたくないことは書かないでください
  3. 運営への連絡は保護者だけの部屋で。運営は仕事をしながら運営しているため、返事は数日以内になります(すぐにはお返事できません)
  4. ルール違反や、お子さんが嫌な思いをしたときは、保護者だけの部屋でお知らせください。指導の中身への口出しはお受けしません

ルール違反

  • ルール違反があった場合は、退部していただくことがあります(部員・保護者とも)

何か起きた時の手順(保護者の方へ)

バスケのコソ練部で、困ったことや危ないことが起きた時に、運営者が何をするかをまとめました。
運営する大人は MOTO 1人です。仕事の合間に見ているため、すぐに気づけない時間があります。
そのため、安全のため、部の書き込みは機械(AI)でも確認し、危ない書き込みは運営者に知らせが届くようにしています。 読むのは安全の確認のためだけで、AI がお子さんに返事をすることはありません。

運営者がすること

こんな時運営者がすること
命や体に関わること、性的な書き込み、外で会おうとする誘い、部員でない大人がまぎれ込んだ時確認でき次第、書き込みを消し、関わった人を部から外します。保護者の方へ、部のメールでご連絡します。 必要な時は警察や児童相談所に相談します
悪口やからかいが続く、本名・学校名・顔が出た、部員どうしの個別メッセージ確認でき次第、書き込みを消し、部の部屋でルールを伝えます。くり返す時は保護者の方へご連絡し、それでも続く時は退部をお願いすることがあります
言い合いや、部と関係ない話で荒れた時部の部屋でルールを短く伝えます
  • どの場合も、何があったかを後で説明できるよう、消す前に記録を残します。 記録は記録した日から3か月以内に消します。命や安全に関わり、警察などに伝える必要がある時を除いて、外には出しません。
  • ほかの部員の前で、誰がしたかを名指しすることはありません。
  • お子さんと個別にやり取りすることはありません。 運営者から保護者の方へのメールは、受付・招待などのお知らせと、安全に関わる時のご連絡だけです(お子さんには個別に連絡しません)。
